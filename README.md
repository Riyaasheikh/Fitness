# 🌿 Vibrant Wellness

A modern, cinematic single-page wellness landing page built with React, TypeScript, Tailwind CSS, and Framer Motion. The website focuses on holistic wellness with an immersive user experience, premium glassmorphism UI, smooth animations, and responsive design.


## ✨ Features

- Full-screen cinematic hero section
- Responsive navigation with mobile menu
- Custom Liquid Glass UI components
- Smooth scroll animations
- Wellness Programs section
- Healing Journey timeline
- Meet the Experts
- Client Testimonials
- FAQ Accordion
- Call to Action section
- Fully responsive design
- Modern dark luxury interface

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Riyaasheikh/Fitness.git
```

Navigate to the project

```bash
cd Fitness
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
